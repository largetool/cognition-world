# 31_导出数据库结构

## 任务

导出当前 Supabase 数据库中所有表的结构，生成 CREATE TABLE 语句，方便我在新的 Supabase 项目中重建数据库。

## 需要导出的内容

### 1. 列出所有表
用 SQL 查询列出 public schema 下所有表名：
```sql
SELECT table_name FROM information_schema.tables 
WHERE table_schema = 'public' AND table_type = 'BASE TABLE';
```

### 2. 每个表的建表语句
对上面查到的每一张表，输出完整的 CREATE TABLE SQL，包括：
- 字段名、类型、默认值
- 主键
- 外键约束
- 索引

### 3. Row Level Security (RLS) 策略
对每张开启了 RLS 的表，列出其所有策略的创建语句（CREATE POLICY）。

### 4. 枚举类型/自定义类型
如果有自定义类型，也导出。

### 5. 触发器/函数
如果有 trigger 或 function，也导出。

## 输出格式

把上面所有内容按顺序整理成一个完整的 `.sql` 文件，可以直接在新 Supabase 项目的 SQL Editor 中执行。
